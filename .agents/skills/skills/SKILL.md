# Published skills

- A skill lives in `skills/<name>/`, and the `name` in its `SKILL.md` frontmatter equals the folder name.
- Next to `SKILL.md` there is a `README.md` with the theory behind the skill.
- Every skill is listed in the root `README.md`.
- Tests of a skill go in `tests/skills/<name>/`.
